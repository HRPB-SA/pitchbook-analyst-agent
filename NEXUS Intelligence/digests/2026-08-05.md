In software and API contexts, the "latest" alias is the canonical example — it routes all non-pinned requests to whatever version the provider designates as current.<br><br>\*Mechanism (the why):\* Defaults work because they exploit the asymmetry between the effort required to change a setting and the effort required to accept the current one. For API developers, re-pinning a model version requires testing, staging, and deployment work; accepting the alias requires nothing. The provider who controls the default therefore controls adoption velocity without winning a quality competition.<br><br>\*Live anchor:\* xAI's migration of \`grok-voice-latest\` to Think Fast 2.0 on August 5 is a textbook routing-default play.
