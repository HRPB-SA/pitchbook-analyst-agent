# Companies

One folder per tracked company. Add a new one any time:
`python3 -m engine add <slug> "<Company Name>"` (or just ask; research seeds
it on the first report). The universe list is `universe.json`.

Inside each company folder:

- **PROFILE.md**: the readable canonical record: every fact with value,
  source, date, tier. Regenerated by `python3 -m engine export <slug>`.
- **Category drop zones**: put anything you have into the matching folder and
  the next research pass ingests and cites it (tiered like any other source):
  - `financials/` revenue, margins, P&L material
  - `valuation-and-deals/` rounds, marks, term sheets
  - `products/` product lines, launches, pricing
  - `people/` leadership, headcount, key departures
  - `customers/` counts, retention, named accounts
  - `competition/` rivals, market position
  - `filings/` SEC and regulatory documents
  - `news-and-events/` dated events, articles
  - `notes/` your own working notes
- **store/**: the machine layer; do not hand-edit. Immutable dated snapshots,
  the canonical profile.json, frozen conflicts, supersession history, and
  computed trends. The engine maintains it; every report reads from it.
